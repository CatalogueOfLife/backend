Catalogue of Life

This is a “release in a box”: one published Catalogue of Life release, served by its own copy of the ChecklistBank API together with its own database and search index.

The living Catalogue of Life — every release, the source datasets behind them and the tools that build them — is at www.catalogueoflife.org, with the full API and editing platform at www.checklistbank.org.

API

The read API of this release is served on port 8080 and needs no dataset key: /taxon/{id}, /nameusage/search?q=, /tree. This site reaches the very same API through /api/.
