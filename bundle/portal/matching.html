Name matching

Upload a CSV or TSV file of names and match every row against this release. The matched file is streamed straight back to your browser — nothing is stored here.

Drop a CSV or TSV file here, or click to choose one

The first row must be a header containing a scientificName column

Input columns

scientificName is required. ID, authorship, rank, code and status are used when present, as are classification columns such as kingdom, phylum, class, order, family and genus — they disambiguate homonyms. Every column you supply is echoed back prefixed with original_.

How it works

Matching runs synchronously against the names index shipped with this bundle, so the result arrives as one download when the whole file is done. Large files simply take longer; keep the tab open until the download appears.

The same endpoint is available directly for scripting: 

curl -X POST \
  -H 'Content-Type: text/csv' \
  --data-binary @names.csv \
  'http://localhost:8080/match/nameusage?format=CSV' \
  -o matched.zip

The response is a ZIP holding one matched table.
