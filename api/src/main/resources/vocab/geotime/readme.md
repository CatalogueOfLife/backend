geotime.csv is generated by GeoTimeIscConverter, which has to be run manually whenever one of the following files changes:

 - chart-2026-06.ttl is the 2026-06 International Chronostratigraphic Chart with ages, ranks, colours and labels.
   It is chart.ttl of https://github.com/i-c-stratigraphy/chart at commit 81618a865cdb04998355a302f3e859908a080c0e
 - patch.csv corrects errors of the chart. Fields are start, end and removeLabel, and the conversion fails for any patch that
   the chart does not need anymore, so remove those when updating the chart.
 - legacy-labels.csv keeps all labels of the 2020 chart we used before, as the new chart has less of them, e.g. none
   for LowerDevonian. Parsing would otherwise fail for values it understands today, including the old MiddlePleistocene.

Colours follow the Commission for the Geological Map of the World.
GeoTimeTest verifies that all time spans of the csv fit into their parent and leave no gaps.
