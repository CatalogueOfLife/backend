Homotypic Grouping test data.

This archive is the origin of the `homgroup` test data set in `core/src/test/resources/test-data/homgroup`,
which the TestDataRule loads. Those CSV files are maintained by hand and have since diverged from this
archive, so do not expect to rebuild them from it - edit the CSV files directly instead.
See `core/src/test/resources/test-data/README.md`.
