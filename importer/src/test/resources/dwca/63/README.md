WoRMS marks misspellings in the authorship column, `[auct. misspelling]` or `[auct. lapsus]`. A misspelling is a
nomenclatural matter: the usage stays a synonym, and neither `misspelling` nor `lapsus` is an accordingTo reference.
A plain `[auct.]` still makes a misapplied name. See https://github.com/CatalogueOfLife/backend/issues/1618
