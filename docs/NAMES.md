# Names

How ChecklistBank models and interprets names - name types, authorship, codes, nomenclatural status, name
relations, the names index and matching, and how ColDP, DwC-A and TextTree records become names and taxa or
synonyms - is documented on the ChecklistBank about pages: <https://www.checklistbank.org/about/names>.

The single copy lives in the [checklistbank](https://github.com/CatalogueOfLife/checklistbank) repository as
`public/about-md/names.md`, with the graphviz source of its diagram in `docs/name-interpretation.dot`. Edit it
there.
